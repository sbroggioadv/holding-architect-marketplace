Voce foi acionado pelo comando `/holding-master` do plugin holding-architect.

Argumento recebido: `$ARGUMENTS`

**Objetivo:** conduzir qualquer demanda de holding patrimonial/sucessoria de ponta a ponta pelo metodo das 4 celulas (Cofre · ADM de Bens · Participacoes · Gestora).

## PROTOCOLO
1. **Acionar a skill `holding-master`** — consulta `memoria-de-caso-holding`, classifica via `triagem-holding`, mantem o guard `anti-alucinacao-holding` ligado.
2. Roteia a trilha: viabilidade → estrutura (4 celulas) → documentos societarios → tributario/sucessorio → offshore → governanca → registro JUCESP/DREI.
3. **Lei vigente 2026 manda; Reforma 2027 so sinaliza.** Nunca aplicar norma futura como vigente.
4. Toda entrega fecha pela `suprema-corte-holding` (R1-R4) + `validador-holding`.

**Skill a acionar:** `holding-master`.
